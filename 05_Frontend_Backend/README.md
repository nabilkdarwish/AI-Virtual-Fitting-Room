# 💻 05_Frontend_Backend — (مسؤولية: نور)

أهلاً يا نور! في هذا الجزء أنتِ مسؤولة عن **واجهة المستخدم، المساعد الصوتي، وتوصيل النظام بالبروجيكتور**:
تحويل كل أكواد معالجة الصور وموديلات الذكاء الاصطناعي إلى منتج حقيقي وتفاعلي يراه المستخدم ويتحكم فيه بصوته أو باللمس، مع عرضه كمرآة ذكية كاملة على شاشة العرض أو البروجيكتور.

---

## 🎯 وظيفتك باختصار
1. بناء واجهة المرآة الذكية (Virtual Mirror UI) لعرض الصورة النهائية القادمة من **نبيل**.
2. بناء كتالوج تصفح الملابس (Catalog Selector) لعرض الملابس (رجالي، حريمي، أطفال) واختيار القطعة بالضغط عليها.
3. تفعيل الأوامر الصوتية (Voice Control) باستخدام المايكروفون (مثل: "Next Shirt", "Show Red T-Shirt", "Change Size").
4. تجهيز نمط عرض البروجيكتور (Projector Extended Display): شاشة عرض كاملة نظيفة بدون أزرار لتعرض الشخص وكأنه أمام مرآة بروجيكتور حقيقية.
5. توفير خادم محلي (FastAPI أو Flask / WebSockets) لتبادل البيانات بسلاسة بين الواجهة وخوارزميات المعالجة.

---

## 📂 ملفاتك والمطلوب كتابته في كل ملف:

### 1. في مجلد الباك إند (`backend/`):
- `main.py`: تشغيل خادم الويب وربط مسارات الـ API.
- `api_routes.py`: روابط جلب قائمة الملابس، تفاصيل القطع، وتأكيد اختيار الطقم.
- `websocket_manager.py`: قناة اتصال سريعة للبث وإرسال إشعارات التغيير في اللحظة نفسها.
- `session_manager.py`: تتبع اختيارات المستخدم الحالية (القطعة المختارة، المقاس، اللون).
- `voice_controller.py`: التقاط الصوت من المايك وفهم الكلمات المفتاحية لتغيير الطقم تلقائياً.
- `projector_controller.py`: ضبط إعدادات الشاشة الثانية ومخرج الـ HDMI.
- `application_config.py`: إعدادات المنافذ (Ports) وعناوين الـ Localhost.

### 2. في مجلد الواجهة (`frontend/`):
- شاشة المرآة (`VirtualMirrorView`): شاشة تعرض الفيديو المباشر للمستخدم وعليه الملابس.
- شاشة البروجيكتور (`ProjectorView`): شاشة سوداء أنيقة تعرض الفيديو بملء الشاشة مع شعار المشروع.
- شريط الكتالوج (`CatalogSelector`): قائمة سفلية أو جانبية لاختيار التيشيرتات والقمصان.
- مؤشر الصوت (`VoiceIndicator`): أيقونة توضح عندما يستمع النظام لصوت المستخدم.

## 📥 المدخلات والمخرجات:
- **المدخل لك:** الإطار النهائي الملبس من محرك **نبيل** (`04_Virtual_TryOn`).
- **المخرج منك:**
  - واجهة المستخدم التفاعلية المعروضة للمستخدم وللدكتور في المناقشة.
  - إشارة القطعة المختارة (Selected Garment ID) التي يتم إرسالها لـ **نبيل** لتحميلها.

## 🛠️ أهم المكتبات والتقنيات المقترحة:
- **الباك إند:** `fastapi` + `uvicorn` (أو `opencv` GUI سريع للتبسيط)، ومكتبة `SpeechRecognition` أو `faster-whisper` للصوت.
- **الفرونت إند:** `React` + `Tailwind CSS` (أو واجهة `Streamlit / PyQt` كخيار بديل وسريع جداً لو رغبتِ في إنجاز سريع).
