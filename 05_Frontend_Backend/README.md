# الواجهة والتحكم — Python + Streamlit

واجهة المشروع مكتوبة بالكامل ببايثون باستخدام **Streamlit**. لا تحتاج إلى Node.js أو React أو ملف HTML لتشغيلها.

## التشغيل

من جذر المستودع:

```bash
python -m pip install -r 05_Frontend_Backend/requirements.txt
streamlit run 05_Frontend_Backend/frontend/app.py
```

يفتح Streamlit الواجهة في المتصفح. يمكنك التقاط صورة بالكاميرا أو رفع صورة، ثم تصفح الكتالوج حسب الفئة ونوع الملابس واللون، والبحث باسم المنتج أو رقمه، واختيار قطعة وتأكيدها.

## الملفات

- `frontend/app.py`: تطبيق Streamlit وواجهة الكتالوج ومعاينة الصورة والقطعة المختارة.
- `requirements.txt`: اعتماديات الواجهة وخدمات الباك إند.
- `backend/`: مكان خدمات API وWebSocket والتحكم بالبروجيكتور عند تنفيذها.

تعتمد الواجهة على `Dataset/Catalog/catalog_metadata.json` وصور المنتجات الموجودة في `Dataset/Catalog/`.

## حالة تجربة الملابس

الواجهة تعرض صورة المستخدم والقطعة المختارة جنبًا إلى جنب وتحفظ رقم المنتج المختار في جلسة Streamlit. إنشاء صورة مركبة للملابس يحتاج إلى توصيل نموذج Virtual Try-On؛ ملفات الباك إند ونموذج التوليد في المستودع ما زالت هياكل أولية.
