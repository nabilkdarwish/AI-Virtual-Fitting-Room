# 🪞 AI-Powered Real-Time Virtual Fitting Room
### مشروع غرفة قياس الملابس الافتراضية الذكية بالذكاء الاصطناعي
> **Course:** ELE 261 - Image Processing | **Faculty of Engineering, New Ismailia National University**

---

## 💡 فكرة المشروع ببساطة (Project Overview)
المشروع عبارة عن **مرآة ذكية تفاعلية (Virtual Mirror)**:
المستخدم يقف أمام الكاميرا، يختار قطعة ملابس (باللمس أو بالأمر الصوتي)، فيقوم النظام بالتعرف على جسمه وتلبيسه الطقم في الوقت الفعلي وكأنه ينظر في مرآة حقيقية، مع إمكانية عرض النتيجة على شاشة أو بروجيكتور (Projector).

---

## 👥 تقسيم المهام على الفريق (5 أعضاء)

كل عضو في الفريق مسؤول عن مجلد محدد، ولكل مجلد **README خاص به** يشرح المطلوب بالتفصيل:

| العضو | المجلد | الدور والمسؤولية باختصار |
| :--- | :--- | :--- |
| **1. يوسف** | [`01_Computer_Vision/`](./01_Computer_Vision/) | **الكاميرا وتتبع الجسم**: فتح الكاميرا، استخراج نقاط مفاصل الجسم (Pose Landmarks)، وتنعيم الحركة. |
| **2. محمد متولي** | [`02_Image_Processing/`](./02_Image_Processing/) | **معالجة الصورة والعزل**: عزل الشخص عن الخلفية، وعمل ماسك (Mask) لتفريغ مكان الملابس الحالية. |
| **3. محمد علاء** | [`03_AI_Models/`](./03_AI_Models/) | **موديلات الذكاء الاصطناعي**: تجهيز واختبار موديل الـ Virtual Try-On وتوليد صورة الطقم. |
| **4. نبيل (Leader)** | [`04_Virtual_TryOn/`](./04_Virtual_TryOn/) | **محرك التلبيس والدمج**: ضبط مقاس قطعة الملابس لتطابق انحناءات الجسم (Warping) ودمجها بنعومة فوق صورة الشخص. |
| **5. نور** | [`05_Frontend_Backend/`](./05_Frontend_Backend/) | **الواجهة والتحكم والبروجيكتور**: واجهة العرض التفاعلية، التحكم بالأوامر الصوتية، وإرسال الصورة للبروجيكتور. |

## 🔄 مسار تدفق البيانات (ببساطة شديدة: من إيد مين لإيد مين؟)

```
[كاميرا المستخدم]
       │
       ▼
1. يوسف (Computer Vision)
   - بيستلم: فيديو الكاميرا لايف.
   - بيسلّم: إطار الصورة + إحداثيات نقاط الجسم (الكتف، الصدر، الوسط).
       │
       ▼
2. محمد متولي (Image Processing)
   - بيستلم: إطار الصورة من يوسف.
   - بيسلّم: ماسك معزول للجسم، مع تفريغ مكان التيشيرت/القميص (Agnostic Mask).
       │
       ▼
3. نبيل ومحمد علاء (Try-On & AI Models)
   - نبيل: بيعمل Warping لقطعة الملابس الجديدة عشان تاخد نفس مقاس وانحناءات جسم الشخص.
   - محمد علاء: بيطبق موديل التوليد (VTON) لضبط الإضاءة والثنيات الواقعية.
   - نبيل: بيدمج الطقم الجديد على صورة الشخص الأصلية (Compositing).
       │
       ▼
4. نور (Frontend & Projector)
   - بتستلم: الصورة النهائية الملبسة.
   - بتعرضها: في شاشة المرآة الذكية وعلى البروجيكتور، مع استقبال أوامر الصوت (مثل: "Next", "Red Shirt").
```

## 🚀 كيفية تشغيل المشروع وتثبيت المكتبات

1. **إنشاء بيئة عمل افتراضية (Virtual Environment):**
```bash
python3 -m venv venv
source venv/bin/activate  # في لينكس
```

2. **تثبيت المكتبات المطلوبة:**
```bash
pip install -r requirements.txt
```

3. **تشغيل واجهة غرفة القياس المكتوبة ببايثون:**
```bash
pip install -r 05_Frontend_Backend/requirements.txt
streamlit run 05_Frontend_Backend/frontend/app.py
```
ستفتح الواجهة في المتصفح، ومنها يمكنك التقاط صورة أو رفعها واختيار قطعة من الكتالوج.
